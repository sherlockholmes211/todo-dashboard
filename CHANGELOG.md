# Changelog

## 1.1.0

- Added optional task descriptions to the CLI, task editor, and task details.
- Added keyboard date and time pickers and a navigable task edit form.
- Added arrow key priority selection with highlighted direction, and arrow key theme selection with a live settings preview.
- Improved dashboard column alignment and task details layout.

## 1.0.0

- Added task priorities, deadline and effort views, and customizable dashboard colors and columns.
- Prepared the first stable npm release.

## 0.1.0

- Initial release of the CLI, concurrent timers, safe global storage, and Ink dashboard.
